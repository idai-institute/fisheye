Let your host stop an agent
Register a shutdown callback when creating the app. Then choose that workflow in a shutdown rule.
from fisheye_instant.app import create_app

async def stop_agent(workflow_id,
                     environment,
                     idempotency_key):
    await my_agent.stop()

app = create_app(runtime=runtime,
    stop_handlers={
      ("local", "my-workflow"): stop_agent
    })
Your callback controls the actual stop operation. Use the action ID to make repeated host requests safe.

Scoring you can inspect
Fisheye combines the strongest score per detector, behavior source, and graph category over the last five minutes using 100 × (1 − ∏(1 − channel score)). Repeated observations from the same channel do not add up.
It is a heuristic indicator, not a probability or a guarantee of safety. Missing detector coverage and stale workflows are shown separately. Rules apply to each workflow and environment independently.
Warning and critical labels use 60 and 85. Your response thresholds are independent of these display labels.
